Autocomplete 自动补全 ​

自动完成输入组件，适合远程搜索和候选项补全。

导出 ​

DasAutocomplete、DasAutocompleteRef

基础用法 ​

基础用法
展示 list 模式、字段映射、禁用项、清空和 change 回显。
<template>
  <div class="autocomplete-demo">
    <DasAutocomplete
      v-model="keyword"
      mode="list"
      :options="options"
      :field-names="{ label: 'label', children: 'children' }"
      width="300px"
      clearable
      placeholder="搜索应用"
      @change="lastChange = $event"
    />
    <div class="autocomplete-demo__result">change：{{ lastChange || '暂无' }}</div>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import { DasAutocomplete } from '@das-fed/upf-ui/packages/components/autocomplete'

const keyword = ref('')
const lastChange = ref('')
const options = [
  { label: '基础应用', value: 'basic' },
  { label: '组件文档', value: 'docs' },
  { label: '数据中心', value: 'data' },
  { label: '调度中心', value: 'scheduler', disabled: true },
]
</script>

<style scoped>
.autocomplete-demo {
  display: grid;
  gap: 12px;
}

.autocomplete-demo__result {
  color: var(--upf-text-secondary);
  font-size: 13px;
}
</style>

模式切换 ​

模式切换
对比 tree 与 list 两种模式，展示全路径回显、路径更新和节点点击事件。
<template>
  <div class="autocomplete-mode-demo">
    <DasAutocomplete
      v-model="treeKeyword"
      v-model:path="treePath"
      mode="tree"
      :options="treeOptions"
      :field-names="{ label: 'label', children: 'children' }"
      node-key="label"
      show-full-path
      width="320px"
      placeholder="树模式搜索"
      @node-click="lastNode = $event.label"
    />
    <DasAutocomplete
      v-model="listKeyword"
      mode="list"
      :options="listOptions"
      :field-names="{ label: 'label', children: 'children' }"
      width="320px"
      placeholder="列表模式搜索"
    />
    <div class="autocomplete-mode-demo__result">树节点：{{ lastNode || '暂无' }}，路径：{{ treePath || '暂无' }}</div>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import { DasAutocomplete } from '@das-fed/upf-ui/packages/components/autocomplete'

const treeKeyword = ref('')
const listKeyword = ref('')
const treePath = ref('')
const lastNode = ref('')
const treeOptions = [
  {
    label: '平台中心',
    children: [
      { label: '前端组' },
      { label: '架构组' },
    ],
  },
  {
    label: '业务中心',
    children: [
      { label: '运营组' },
      { label: '交付组' },
    ],
  },
]
const listOptions = [
  { label: '基础应用' },
  { label: '组件文档' },
  { label: '数据中心' },
]
</script>

<style scoped>
.autocomplete-mode-demo {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
  align-items: center;
}

.autocomplete-mode-demo__result {
  width: 100%;
  color: var(--upf-text-secondary);
  font-size: 13px;
}
</style>

查看态与回显 ​

查看态与回显
展示查看态和仅文本展示模式，适合表格或详情页回显。
<template>
  <div class="autocomplete-view-demo">
    <DasAutocomplete
      v-model="viewValue"
      mode="list"
      :options="options"
      :field-names="{ label: 'label', children: 'children' }"
      width="280px"
      is-view
    />
    <DasAutocomplete
      v-model="plainValue"
      mode="list"
      :options="options"
      :field-names="{ label: 'label', children: 'children' }"
      :show-input-dom="false"
      width="220px"
    />
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import { DasAutocomplete } from '@das-fed/upf-ui/packages/components/autocomplete'

const viewValue = ref('组件文档')
const plainValue = ref('数据中心')
const options = [
  { label: '基础应用' },
  { label: '组件文档' },
  { label: '数据中心' },
]
</script>

<style scoped>
.autocomplete-view-demo {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
  align-items: center;
}
</style>

API ​

Attributes ​

属性名说明类型默认
mode可选tree/list 默认为tree'tree' / 'list'tree
model-value / v-model当前输入值string—
is-view是否是查看状态boolean—
width宽度number / string—
size尺寸'default' / 'table'—
options选项[{value:'value'}]any[]必填
placement弹出位置'top' / 'top-start' / 'top-end' / 'bottom' / 'bottom-start' / 'bottom-end'—
max-count下拉选择的数量，超过overflow-y:autonumber—
offset选项出现位置的偏移量number—
popper-options{modifiers: [{name: 'computeStyles',options: {gpuAcceleration: false}}]}Record<string, any>—
show-full-path是否回显包括父级的全路径boolean必填
field-names字段名称FieldNamesOptions & any—
tree-options树配置any—
path树节点路径 同tree组件pathany—
node-key树节点标识 同tree组件node-key 如果要使用path路径进行回显 只能设置为id，因为tree path根据id追溯层级string—
show-input-dom是否显示das-Input 如果是false则只显示文本 默认为truebooleantrue

Events ​

事件名说明参数
update:modelValue—val: string
input—val: string
change—val: string
node-click节点点击 val:当前节点值val: any
update:path更新树路径val: any

字段名说明类型
label—string
children—string
