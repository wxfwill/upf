Dimple Layout 可视化布局 ​

可视化布局编辑与渲染能力，适合画布、流程和低代码布局场景。

导出 ​

DimpleLayoutEditor、getDimpleLayoutEditorRef、DimpleLayoutRender、DimpleLayoutHelper

基础用法 ​

基础用法
展示通过 canvas 实例加载布局 JSON 数据并自适应渲染的基础方式。
<template>
  <div class="dimple-layout-demo">
    <DimpleLayoutRender v-model:canvas="canvas" />
  </div>
</template>

<script setup lang="ts">
import { onMounted, ref } from 'vue'
import { DimpleLayoutRender } from '@das-fed/upf-ui/packages/components/dimple-layout'
import type { DimpleLayoutCanvas } from '@das-fed/upf-ui/packages/components/dimple-layout/type'

const canvas = ref<DimpleLayoutCanvas | null>(null)

const renderData = {
  cells: [
    {
      id: 'card-title',
      shape: '$text',
      position: { x: 40, y: 40 },
      size: { width: 220, height: 36 },
      data: {
        text: '数据驾驶舱',
        style: { fontSize: '24px', fontWeight: '600', color: '#1F2D3D' },
      },
      zIndex: 1,
    },
    {
      id: 'card-status',
      shape: '$text',
      position: { x: 40, y: 98 },
      size: { width: 280, height: 28 },
      data: {
        text: '运行状态：正常 | 今日告警：2 条',
        style: { fontSize: '14px', color: '#5B6B82' },
      },
      zIndex: 2,
    },
  ],
  backgroundConfig: { color: '#F4F7FB' },
  container: { width: 360, height: 220 },
}

/**
 * Render 组件通过 canvas 实例加载 JSON 数据，这里保留最小可运行示例。
 */
onMounted(() => {
  if (!canvas.value) return
  canvas.value.fromJSON(renderData)
  canvas.value.zoomToFit({ padding: 16 })
})
</script>

<style scoped>
.dimple-layout-demo {
  height: 260px;
  overflow: hidden;
  border: 1px solid var(--upf-border-color);
  border-radius: 8px;
}
</style>

字段名说明类型
image背景图片地址string
position背景图片位置，默认为 { x: 0, y: 0 }{ x: number; y: number }
size背景图片大小，默认和画布宽高一致{ height: number; width: number }
angle背景图片的旋转角度，默认为0number
opacity背景透明度number

onDraw绘制时触发() => any
onEdit编辑时触发() => any
onEditCancel编辑取消时触发() => any
onClear清除时触发() => any

字段名说明类型

transformOptions每次右键菜单加载时执行的配置转换方法(e: any, options: ContextMenuOptions) => ContextMenuOptions

DrawOptions ​

字段名说明类型
nodeOptions节点的配置Node.Config
firstNodeOptions首个绘制节点的配置Node.Config
firstNodeRestOnFinish首个绘制节点完成后，恢复成统一的节点配置,默认为trueboolean
edgeOptions边的配置Edge.Config
pointerOptions指示点的配置{ containerStyle?: CSSProperties tipStyle?: CSSProperties tipText?: string tipTextOffsetY?: number }
polyline是否最后转换为多边形，可以支持整体移动、设置背景颜色等boolean
polylineOptions如果转换成多边形，这个配置可以设置多边形的样式，可以配置背景颜色和描边粗细颜色等Node.Config
closure绘制完自动闭合boolean
closureEdgeOptions自动闭合边的配置，默认使用edgeOptions，如果传了这个，会以此配置优先并合并Edge.Config
autoStop自动停止绘制boolean
loop绘制结束后又重新开始开始绘制，直到下一次停止boolean
unityHistory是否把此次绘制作的历史记录统一为一次记录。这样设置后撤回会把整个绘制的内容全部撤回boolean
onClick每次点击时的回调(
event点击时event，可能的点击来源：空白处、点、边any
data点击时产生的数据{ node: Node edge: Edge | undefined nodeList: Ref<Node[]> edgeList: Ref<Edge[]> }, ) => any
disabled每次点击时的返回禁用状态，如果返回true，那么此次点击不会产生任何绘制效果(
event点击时event，可能的点击来源：空白处、点、边any
data点击时已经存在的数据{ nodeList: Ref<Node[]> }, ) => boolean
onStop停止绘制时的回调(
data点击时产生的数据DrawResultData, ) => any
