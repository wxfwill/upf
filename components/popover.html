Popover 气泡卡片 ​

气泡卡片组件。

导出 ​

DasPopoverRef、DasPopover

基础用法 ​

基础用法
展示受控 visible、确认/取消事件、点击外部事件和默认内容插槽。
<template>
  <div class="popover-demo">
    <div class="upf-demo-row">
      <DasPopover
        v-model:visible="visible"
        title="确认操作"
        content="确认后会提交当前配置。"
        placement="bottom-start"
        show-btns
        @confirm="confirm"
        @cancel="cancel"
        @click-outside="lastAction = '点击外部区域'"
      >
        <template #reference>
          <DasButton btn-type="default">受控 Popover</DasButton>
        </template>
      </DasPopover>
      <DasPopover title="自定义内容" width="280px" placement="right">
        <template #reference>
          <DasButton btn-type="default">自定义内容</DasButton>
        </template>
        <div class="popover-demo__content">
          <strong>审批提醒</strong>
          <span>支持默认内容插槽，可放入描述、状态和操作区。</span>
        </div>
      </DasPopover>
    </div>
    <div class="popover-demo__result">最近操作：{{ lastAction }}</div>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import { DasButton } from '@das-fed/upf-ui/packages/components/button'
import { DasPopover } from '@das-fed/upf-ui/packages/components/popover'

const visible = ref(false)
const lastAction = ref('暂无')

const confirm = () => {
  lastAction.value = '确认'
  visible.value = false
}

const cancel = () => {
  lastAction.value = '取消'
  visible.value = false
}
</script>

<style scoped>
.popover-demo {

  color: var(--upf-text-secondary);
  font-size: 13px;
}
</style>

Attributes ​

属性名说明类型默认

content内容string—
