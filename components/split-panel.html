Split Panel 分割面板 ​

分割面板组件。

导出 ​

DasSplitPanel、DasSplitPanelRef

基础用法 ​

基础用法
展示左右面板拖拽分栏、折叠与默认比例恢复。
<template>
  <div class="split-panel-demo">
    <DasSplitPanel
      :box-style="{ height: '220px', border: '1px solid var(--upf-border-color)', borderRadius: '6px' }"
      :default-split="{ first: 0.36, second: 0.64 }"
      :first-min="160"
      :second-min="260"
      @on-left="lastAction = '左侧已收起'"
      @on-right="lastAction = '右侧已收起'"
      @on-default="lastAction = '恢复默认比例'"
      @on-mouse-up="lastAction = '拖拽结束'"
    >
      <template #firstSlot>
        <div class="split-panel-demo__pane">
          <strong>筛选树</strong>
          <span>左侧面板可拖拽改变宽度，也可通过中间按钮折叠。</span>
        </div>
      </template>
      <template #secondSlot>
        <div class="split-panel-demo__pane split-panel-demo__pane--main">
          <strong>详情内容</strong>
          <span>右侧面板随剩余空间自适应，适合列表详情、配置面板等工作台场景。</span>
        </div>
      </template>
    </DasSplitPanel>
    <div class="split-panel-demo__result">{{ lastAction }}</div>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import { DasSplitPanel } from '@das-fed/upf-ui/packages/components/split-panel'

const lastAction = ref('可拖拽中间分割线或点击折叠按钮')
</script>

API ​

Attributes ​

属性名说明类型默认
can-fold折叠功能是否启用boolean—
can-drag拖动功能是否启用boolean—
box-style面板外框样式StyleValue—
default-split面板默认分割比例(number类型且小于1，视为百分比)any—
first-min第一个面板的最小阈值(number类型且小于1，视为百分比)number / string—
second-min第二个面板的最小阈值(number类型且小于1，视为百分比)number / string—
default-close初始状态收起哪一边, 不传按defaultSplit设置初始值'first' / 'second'—
  • 类型源码：upf/framework/packages/das-ui/packages/components/split-panel/src/type.d.ts
