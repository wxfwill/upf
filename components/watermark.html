Watermark 水印 ​

水印组件。

导出 ​

DasWatermark

基础用法 ​

基础用法
在业务内容容器上添加基础水印。
<template>
  <DasWatermark content="UPF UI">
    <div class="watermark-demo__content">
      <p class="watermark-demo__title">业务内容区域</p>
      <p class="watermark-demo__desc">水印覆盖在容器内部，不影响业务内容正常排版。</p>
    </div>
  </DasWatermark>
</template>

<script setup lang="ts">
import { DasWatermark } from '@das-fed/upf-ui/packages/components/watermark'
</script>

<style scoped>
.watermark-demo__content {
  min-height: 180px;
  padding: 24px;
  border: 1px solid var(--upf-border-color);
  border-radius: 6px;
  background: var(--upf-bg-primary);
}

.watermark-demo__title,
.watermark-demo__desc {
  margin: 0;
}

.watermark-demo__title {
  color: var(--upf-text-primary);
  font-size: 18px;
  font-weight: 700;
  line-height: 28px;
}

.watermark-demo__desc {
  margin-top: 8px;
  color: var(--upf-text-secondary);
  line-height: 22px;
}
</style>

自定义参数 ​

自定义参数
自定义水印文字、字号、颜色、间距和旋转角度。
<template>
  <div class="watermark-custom-demo">
    <div class="watermark-custom-demo__controls">
      <button
        v-for="item in presets"
        :key="item.label"
        type="button"
        class="watermark-custom-demo__control"
        :class="{ 'is-active': active.label === item.label }"
        @click="active = item"
      >
        {{ item.label }}
      </button>
    </div>
    <DasWatermark
      :content="active.content"
      :font="{ color: active.color, fontSize: active.fontSize }"
      :rotate="active.rotate"
      :gap="active.gap"
    >
      <div class="watermark-custom-demo__content">
        <p>{{ active.label }}</p>
        <span>字体 {{ active.fontSize }}px · 旋转 {{ active.rotate }}° · 间距 {{ active.gap.join(' / ') }}</span>
      </div>
    </DasWatermark>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import { DasWatermark } from '@das-fed/upf-ui/packages/components/watermark'

const presets = [
  { label: '内部使用', content: 'Internal Use', color: 'rgba(49, 94, 251, 0.15)', fontSize: 18, rotate: -22, gap: [120, 80] },
  { label: '评审环境', content: 'Review Only', color: 'rgba(18, 170, 83, 0.16)', fontSize: 16, rotate: -14, gap: [96, 72] },
  { label: '敏感数据', content: 'Confidential', color: 'rgba(245, 108, 108, 0.15)', fontSize: 20, rotate: -28, gap: [140, 92] },
]
const active = ref(presets[0])
</script>

多行水印 ​

多行水印
使用多行 content 展示内部系统、截图留痕等水印场景。
<template>
  <DasWatermark :content="['UPF UI', userName, 'Confidential']" :font="{ color: 'rgba(48, 49, 51, 0.14)' }">
    <div class="watermark-multi-demo">
      <div class="watermark-multi-demo__header">
        <div>
          <p>数据看板截图</p>
          <span>多行水印适合内部平台、评审环境和截图留痕。</span>
        </div>
        <input v-model="userName" maxlength="12" aria-label="水印用户名" />
      </div>
      <div class="watermark-multi-demo__grid">
        <div v-for="item in cards" :key="item.label" class="watermark-multi-demo__card">
          <span>{{ item.label }}</span>
          <strong>{{ item.value }}</strong>
        </div>
      </div>
    </div>
  </DasWatermark>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import { DasWatermark } from '@das-fed/upf-ui/packages/components/watermark'

const userName = ref('张三')
const cards = [
  { label: '今日访问', value: '12,840' },
  { label: '处理工单', value: '326' },
  { label: '风险告警', value: '18' },
]
</script>
