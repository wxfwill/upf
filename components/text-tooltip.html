Text Tooltip 文本提示 ​

文本溢出提示指令。

导出 ​

vDasTooltip

基础用法 ​

基础用法
只有文本实际溢出时才显示完整内容提示，适合窄区域标题。
<template>
  <div class="text-tooltip-demo">
    <label>
      宽度
      <input v-model.number="width" type="range" min="120" max="360" />
      <span>{{ width }}px</span>
    </label>
    <div v-das-tooltip class="upf-demo-ellipsis text-tooltip-demo__text" :style="{ maxWidth: `${width}px` }">
      这是一段较长的文本，超出容器后通过文本提示指令展示完整内容。
    </div>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import { vDasTooltip } from '@das-fed/upf-ui/packages/components/text-tooltip'

const width = ref(260)
</script>

<style scoped>
.text-tooltip-demo {
  display: grid;
  gap: 12px;
}

.text-tooltip-demo label {
  display: inline-flex;
  flex-wrap: wrap;
  align-items: center;
  gap: 8px;
  color: var(--upf-text-secondary);
  font-size: 13px;
}

.text-tooltip-demo__text {
  padding: 8px 10px;
  border: 1px solid var(--upf-border-color);
  border-radius: 6px;
  background: var(--upf-bg-secondary);
}
</style>

基础长文本 ​

基础长文本
通过缩窄容器演示长文本省略和悬停回显。
<template>
  <div class="text-tooltip-long-demo">
    <div
      v-for="item in rows"
      :key="item.label"
      v-das-tooltip
      class="upf-demo-ellipsis text-tooltip-long-demo__item"
      :style="{ maxWidth: `${item.width}px` }"
    >
      {{ item.label }}
    </div>
  </div>
</template>

<script setup lang="ts">
import { vDasTooltip } from '@das-fed/upf-ui/packages/components/text-tooltip'

const rows = [
  { width: 180, label: '这是一段较长的文本，适合列表列和描述信息。' },
  { width: 260, label: '宽一点的容器会保留更多正文，仍然在溢出时显示完整提示。' },
  { width: 360, label: '当文本没有溢出时，指令不会额外打扰用户。' },
]
</script>

<style scoped>
.text-tooltip-long-demo {
  display: grid;
  gap: 10px;
}

.text-tooltip-long-demo__item {
  padding: 8px 10px;
  border: 1px solid var(--upf-border-color);
  border-radius: 6px;
  background: var(--upf-bg-primary);
}
</style>
