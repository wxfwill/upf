导出 ​

DasStep

基础用法 ​

基础用法
展示单个步骤项在 Steps 中的标题、描述和状态推进。
<template>
  <div class="step-demo">
    <DasSteps :active="active" status="process">
      <DasStep title="创建" description="录入基础信息" />
      <DasStep title="审核" description="等待负责人确认" />
      <DasStep title="完成" description="发布成功" />
    </DasSteps>
    <DasButton btn-type="primary" size="small" @click="active = active >= 2 ? 0 : active + 1">推进步骤</DasButton>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import DasButton from '@das-fed/upf-ui/packages/components/button'
import { DasStep } from '@das-fed/upf-ui/packages/components/step'
import { DasSteps } from '@das-fed/upf-ui/packages/components/steps'

const active = ref(1)
</script>

<style scoped>
.step-demo {
  display: grid;
  gap: 16px;
}
</style>

DasTabsoptionsType Attributes ​

属性名说明类型默认
key对应 activeKeystring / number—
tab选项卡头显示文字string—
disabled是否禁用boolean / Function—
force-render被隐藏时是否渲染 DOM 结构boolean—
tab-slottab显示文字插槽string—
close-icon-slot关闭图标插槽string—
content-slot显示内容插槽string [propName: string]: any—

Props Attributes ​

属性名说明类型默认
type页签类型，可选 line、card、 editable-card'line' / 'card' / 'editable-card'—
tabs-styletabs的样式对象StyleValue—
size尺寸（基础页签默认为medium,动态页签默认为small,动态页签默认为large）'large' / 'medium' / 'small'medium
contextmenu是否需要右键菜单boolean—
width宽度string / number—
options子项Array<DasTabsoptionsType>必填
constom-menu-list右侧菜单Array<menuListType>—
defualt-props—Record<any, any>—
