安装 ​

使用 pnpm ​

bash
pnpm add @das-fed/upf-ui @das-fed/upf-web @das-fed/upf-utils

组件库 peer 依赖：

bash
pnpm add vue element-plus ant-design-vue

当前源码依赖基线可参考：

text
upf/framework/packages/das-ui/package.json

workspace 联调 ​

当前 monorepo 已通过 pnpm-workspace.yaml 纳入 upf 包：

yaml
packages:
  - 'upf/framework/packages/*'

BasicApplication 使用：

json
{
  "dependencies": {
    "@das-fed/upf-ui": "workspace:*",
    "@das-fed/upf-web": "workspace:*",
    "@das-fed/upf-utils": "workspace:*"
  }
}

本地分析和文档示例应优先以 workspace 源码为准，不只根据已发布包行为判断。
