组件开发 ​

目录规范 ​

text
packages/components/<component-name>/
  index.ts
  src/
    Index.vue
    type.d.ts
  i18n/
  theme/

实际文件名可能存在历史差异，例如 index.vue、App.vue、Pagination.vue。新增组件应尽量收敛到统一结构。

入口规范 ​

组件入口通常使用 withInstall：

ts
import { withInstall } from '@das-fed/upf-utils'
import Component from './src/Index.vue'

const DasComponent = withInstall(Component)

export { DasComponent }
export default DasComponent

文档要求 ​

新增或修改组件时，同步更新：

  • 组件源码类型。
  • packages/components/index.ts。
  • docs/upf-ui/components/<component-name>.md。
  • 必要 demo。

验证建议 ​

默认不跑 upf 全量类型构建。修改组件时优先验证受影响包或文档站：

bash
pnpm docs:upf:build

如果修改了组件源码，再按影响范围运行对应包构建或 demo 验证。
