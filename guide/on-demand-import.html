按需引入 ​

推荐新页面按需引入组件：

vue
<script setup lang="ts">
import { DasButton, DasInput, DasTable, DasTableColumn } from '@das-fed/upf-ui'
</script>

命名规则 ​

组件统一使用 Das 前缀：

目录导出
buttonDasButton
inputDasInput
tableDasTable、DasTableColumn
dialogDasDialog
formDasForm
form-itemDasFormItem

源码入口 ​

text
upf/framework/packages/das-ui/index.ts
upf/framework/packages/das-ui/packages/components/index.ts

每个组件目录下的 index.ts 负责导出组件、注册 i18n 或加载主题。
