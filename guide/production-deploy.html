应用部署 ​

业务应用使用 upf-ui 时，应确保以下依赖版本与构建产物一致：

  • vue
  • element-plus
  • ant-design-vue
  • @das-fed/upf-ui
  • @das-fed/upf-web
  • @das-fed/upf-utils

样式加载 ​

应用入口建议加载：

ts
import '@das-fed/upf-web/packages/style'

按需组件如果内部已引入 Element Plus 或 Ant Design Vue 样式，不要在业务侧重复覆盖组件库内部样式。
