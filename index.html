文档边界 ​

本目录只维护 @das-fed/upf-ui 基础组件库文档，范围限定为：

text
upf/framework/packages/das-ui/packages/components

业务组件 business-components 暂不纳入本次文档站，避免基础组件与业务封装边界混淆。

维护原则 ​

  • 组件 API 以源码 src/type.d.ts、defineProps、defineEmits 为准。
  • 示例以 docs/upf-ui/examples 为准，交互与 API 必须回看 upf/framework/packages/das-ui/packages/components 真实实现。
  • 涉及主题、国际化、图标时同步检查 das-web、das-utils 和 BasicApplication 使用方式。
  • 新增组件时需要同步更新 components/index.ts 与本组件文档页。
